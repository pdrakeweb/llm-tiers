# Decisions

**Proposed** awaiting confirmation.

| ID | Decision | Source |
|---|---|---|
| D-001 | A standalone library usable by any Android app, Apache 2.0; apps may depend on it or copy the pattern. | Pete (words): "we should write these as libraries that can be leveraged by ANY android app (with a permissive license) and then the skill should recommend them as dependencies or possible implementation pattern if the author doesn't want to take on the dependency" |
| D-002 | Survey community approaches first and use the best of them. Done 11 Nov 2026 (DESIGN §1, §1a). | Pete (words): "Look for patterns from the community before implementing and use the best approaches." |
| D-003 | SeaWhisper is one input, not a template. | Pete (words): "only as one input to the plan, not as a copy-paste implementation" |
| D-004 | SeaWhisper moves onto the library once the Android module ships. | Pete (words): "file a future task to change SeaWhisper to take on our new llm-tiers library" |
| D-005 | Tiers: on-device (Gemini Nano, then downloadable models), LAN (any OpenAI-compatible server, e.g. LiteLLM or llama.cpp), cloud (OpenRouter or any OpenAI-compatible URL); reachability-checked fallback. | Pete (words), via NextRep D-015/D-016: "make sure this would work if I'm running litellm and llama.cpp somewhere on my local network where if reachable it can use that and if not it can fall back to something else" |
| D-006 | Privacy is a routing rule: identifiers never leave the device; personal data only with per-request approval. | Pete (words), via NextRep D-017 |
| D-007 | Repository and library name `llm-tiers`; repository public from the start; Maven namespace decided before 0.1.0. | Pete (picked) "drivesync + llm-tiers", "Public from the start" |
| D-008 | Maven group and package root `io.github.pdrakeweb`: artifacts `io.github.pdrakeweb:llm-tiers-<module>`, packages `io.github.pdrakeweb.llmtiers.*`. | Pete (picked) "io.github.pdrakeweb", 11 Nov 2026 |
| D-009 | `Result.Answer` gains `incomplete: ProviderFailure? = null`. Non-null means the provider failed after its first token: the text is partial and this is why (ARCHITECTURE §4 first-token commit). | Pete (picked) "Add Answer.incomplete", 11 Nov 2026 |
| D-010 | A pinned provider is never replaced, whatever the failure: the request ends `NoneAvailable` with the reason. This is the strict reading of A-3; ARCHITECTURE §4 could be read as allowing a reported fallback for failures other than `AuthRejected`/`KeyMissing`. A pin also overrides the request's mode, and a pinned provider is tried even while cooling down. | Proposed (T1 implementation) |
| D-011 | `safeToRetry` defaults to false. Failures that prove the request was not processed (`Unreachable`, `AuthRejected`, `KeyMissing`, `RateLimited`, `ContextTooLong`, `ModelNotReady`, `Busy`, `LocalNetworkPermissionDenied`, a failed probe) and `Escalate` always fall back. Ambiguous ones (`Timeout`, `FirstTokenTimeout`, `Stalled`, `Server`, `Other`) fall back only when the request is marked `safeToRetry` or has an idempotency key. Consequence: an unmarked request does not move on after a first-token timeout. | Proposed (T1 implementation) |
| D-012 | A hard deadline bounds the whole request, fallbacks included. When it passes the result is `NoVerdict` and any partial text is dropped. | Proposed (T1 implementation) |
| D-013 | `Blocked` means no provider was tried and privacy (a sensitivity the provider does not accept, or a refused approval) excluded at least one. A short-circuit hook that throws or exceeds 5 s also yields `Blocked`: it fails closed and no model is called. An approval callback that throws or exceeds 2 min counts as a refusal. | Proposed (T1 implementation) |
| D-014 | Health defaults: 3 failures in 60 s take a provider out for 30 s; `Unreachable`, `ModelNotReady`, `LocalNetworkPermissionDenied`, `AuthRejected` and `KeyMissing` take it out at once; `Busy` and `RateLimited` for 10 s. A provider that fails while probing goes out for twice as long, up to 10 min. Health is keyed by provider and network, so a network change starts fresh. LAN and on-device providers are probed (1 s) before use and the result is trusted for 60 s; cloud providers are never probed. | Proposed (T1 implementation) |
| D-015 | Only the latency budget is implemented. A cost budget needs cost data that `Capabilities` does not carry; deferred until a consumer needs it. | Proposed (T1 implementation) |
| D-016 | `Identifier` items are removed for every provider, on-device included ("stripped", DESIGN §3). | Proposed (T1 implementation) |
| D-017 | `:openai` is in-house over OkHttp and kotlinx.serialization (ARCHITECTURE §1). The app names the model and declares its capabilities; `/v1/models` does not report them reliably. | Proposed (T1 implementation) |
| D-018 | `:openai` never follows HTTP redirects and disables OkHttp's silent connection retry: a redirect would re-send the prompt to a host nobody approved, and a silent retry would send a not-safe-to-retry request twice. An `error` object inside a 200 stream is ambiguous for retry safety (never `RateLimited`/`AuthRejected`), because the server had accepted the request. | Proposed (T1 review fix) |
| D-019 | App callbacks (`approve`, short-circuit, `capabilities()`, `probe()`) and provider streams run in jobs that are cancelled but not joined, so one that ignores cancellation cannot hang a request. A learned timeout that fires is forgotten and relearned from the defaults. | Proposed (T1 review fix) |
| D-020 | Android pins (verified 11 Nov 2026): AGP 9.5.1, Gradle 9.9.1, compileSdk 37, library minSdk 26, sample targetSdk 37 so the Android 17 local-network rule is exercised. | Proposed (T2 implementation) |
| D-021 | The cleartext rule is enforced by an OkHttp network interceptor on the connected address (`privateCleartextOnly()`), because a network security config cannot express address ranges. A blocked request surfaces as `Unreachable`. | Proposed (T2 implementation) |
| D-022 | `GeminiNano()` takes no `Context` (the ML Kit client needs none). The conversation is flattened to one prompt; capabilities are text and vision, no JSON schema, context from the model's own token limit. `BUSY`, background-use and battery-quota errors map to `Busy`. | Proposed (T2 implementation) |
| D-023 | The sample app uses plain platform views, no Compose or DI, to keep the library's sample free of extra dependencies. The encrypted key store listed for `:android` in ARCHITECTURE §1 is not in the T2 roadmap row and is not built; the sample keeps the key in memory only. | Proposed (T2 implementation) |
